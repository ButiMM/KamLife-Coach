# Motion best practices

Start at [index.md](index.md): universal rules for performance, design and accessibility.
Read [css-or-motion.md](css-or-motion.md) first when adding animation to a page.

- `client/public/start` and `client/public/plan` are plain HTML with no library: use CSS.
- `client/src` is React with `framer-motion`: see [react.md](react.md).

This folder is the `best-practices` part of the Motion AI Kit only. The Motion MCP server,
the docs search and the paid Motion+ audits are deliberately not installed; do not add them.
