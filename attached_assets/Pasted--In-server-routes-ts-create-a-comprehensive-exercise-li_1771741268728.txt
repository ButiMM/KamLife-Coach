```
*Then update the GET_WORKOUT handler to:*
*1. Get user's programmePhase, trainingMode, age, and injuries*
*2. Select exercises from EXERCISE_LIBRARY based on phase and training mode*
*3. For the day's workout, pick 4-5 exercises cycling through the library*
*4. Build the workout message including: phase name, week number, exercise name, sets, plain English description, modification if user has injuries or is over 60, and reason*
*5. Use GPT to wrap the workout in a personalised coaching message using buildUserContext — so a 55 year old woman gets different energy than a 22 year old man even if the exercises are the same*
*6. Format the message as:*
```
Phase [X]: [Phase Name] — Week [Y]
Today: [Day number of programme]

[Exercise 1 name] — [sets]
[Plain English description]
[Modification if relevant]

[Exercise 2 name] — [sets]
[Plain English description]

[Why today matters — one GPT-generated sentence specific to this user]

Reply DONE when finished.
Restart the server."
